AAROH TECH PORTFOLIO

Files are intentionally kept together in one folder (no assets folder):
- index.html
- style.css
- script.js
- aaroh-tech-logo.png
- project screenshots (.jpg)

PREVIEW
Open index.html in a modern browser. An internet connection is needed for Google Fonts. The site otherwise uses local image files.

BEFORE PUBLISHING
1. The “Start a conversation” button and LinkedIn links open your profile: https://www.linkedin.com/in/sumithra-b-641181425.
2. Verify each project link and make sure you have permission to display all screenshots.
3. Check the page on desktop and mobile after publishing.

NETLIFY
Unzip the downloaded ZIP. Go to https://app.netlify.com/drop and upload the unzipped project folder (or drag the folder's files into the drop area as prompted). For repeat updates, connect a Git repository to Netlify.

This is a static front-end portfolio. It does not include a backend, database, contact form submission service, or analytics tracking.
